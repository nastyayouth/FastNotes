# FastNotes – Telegram-бот для управления задачами голосом

Проект создан как showcase для .NET backend-разработки.

## Технологии

- .NET 8 (ASP.NET Core Web API)
- PostgreSQL + EF Core
- React + Vite + Tailwind
- Telegram.Bot API v22
- Whisper (распознавание речи)

## CI

В проекте настроен CI на базе GitHub Actions, который собирает и тестирует бэкенд на .NET и фронтенд на Node.js.
